# Duolingo Streak Tracker (PT-BR)

Este projeto expõe estatísticas públicas do Duolingo e gera cartões SVG para uso em README do GitHub.

## Links principais

- Documentação principal (EN): [`README.md`](../README.md)
- API de stats: `/api/stats/:username`
- API de card SVG: `/api/card/:username`

## Exemplo de embed

```md
![Duolingo Streak Card](https://duolingo-streak-tracker.vercel.app/api/card/marlonangeli?theme=duo&variant=default)
```

> Nota: os ícones e assets usados no card SVG são resolvidos por URLs públicas
> em tempo de requisição para manter o mesmo resultado localmente e em produção.
